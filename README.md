# SwordDemo —— 第三人称剑术动作 Demo

一个聚焦"手感与物理反馈"的第三人称近战动作 Demo：挥砍三连、格挡破防、弹反（子弹时间）、盾牌投掷与召回、程序化布料披风。角色位移与全部命中判定由物理驱动，动画只负责表演。

- 引擎：Unity 6000.3.10f1（URP）
- 输入：Input System 包（键鼠）

## 玩法

### 操作

| 输入 | 行为                                 |
|---|------------------------------------|
| WASD | 移动（按相机水平朝向解释，斜向自动归一化）              |
| 鼠标 | 环绕视角（半球面轨道，支持负仰角仰视）                |
| 鼠标左键 / J | 挥砍（A → B → C 三连击，攻击期间锁定移动与朝向）      |
| 鼠标右键 / K | 按住 = 举盾格挡；在敌人攻击窗口内按下 = **弹反**；盾不在手上时 = 召回盾牌     |
| 空格 | 按住 = 瞄准投盾（镜头拉近 + 越肩 + 预瞄点）；松开 = 甩出 |
| ESC | 暂停菜单                               |

### 战斗系统

- **三连挥砍**：A/B/C 三段各有实测标定的判定窗口（动画归一化时间区间），前摇与收势不判定；剑尖段做帧间胶囊扫掠，挥得再快也不会漏。
- **格挡与架势**：正面 ±120° 扇区内的来袭伤害被格挡吸收（不掉血、受击反馈照常），代价是消耗架势值；架势耗尽 → **破防**：盾被打飞、硬直一拍。
- **弹反**：敌人处于攻击挥击区间时按下防御触发 —— 敌人时间放慢 10 倍、玩家照常，按左键反击把敌人平推撞飞；不按则时间到无事发生。
- **盾牌**：物理飞行（盘式自旋），命中敌人扣血、箱子击飞、石头弹开；随时右键召回，召回途中撞到敌人同样结算伤害。
- **命中反馈**：所有命中共用同一把冲量标尺（`J = 武器速度 × 有效质量`）：存活者上半身欠阻尼弹簧摆动——轻击小晃、重劈大晃（±14° 饱和），倾倒方向跟随攻击来向，回摆 1~2 次自然归零；
- **命中溅血**：挥砍命中敌人时，在接触点沿剑尖本帧挥扫方向喷出一小撮血滴——血是"被剑刃甩出去"的。粒子走引擎真实重力积分与物理碰撞模块，落地就停住，随时间氧化变暗并淡出。
- **阵亡布娃娃**：死亡瞬间由动画切换为程序化布娃娃（18 个骨骼部件 + CharacterJoint 链）：飞出强度与方向完全由致死一击的冲量决定，且**砍哪飞哪**——整体速度按部件到命中点的距离衰减（尸体绕命中点旋转），被砍中的部位再吃一发带力臂的局部冲量；4 秒后加大阻尼安静下来但不冻结，尸体留在场上可被剑/盾再次推动，相机跟随同步切到骨盆。
- **敌人**：侦测→追击→停步周期攻击（手掌扫掠判定）；被弹反/盾砸后进入踉跄状态机（破防动画 → 平推 → 起身）。
- **场景交互**：Prop 层箱子被剑/盾/爪按冲量击飞（偏心命中自动旋转）；砍到 StoneBlock 弹刀迸火星；灌木被经过时拨动；敌人阵亡的布娃娃会留在场地主角经过会被推动。

## 相关物理实现

| 领域 | 技术 |
|---|---|
| 角色控制 | Rigidbody 速度直控；动画只表演，位移完全由物理决定（主角与敌人同一原则） |
| 帧同步 | 输入缓冲（Update 置位 → FixedUpdate 消费），点击不会因渲染帧与物理步不同步而丢失 |
| 坡地贴合 | `RaycastNonAlloc` 探地 + 把竖直速度钉成"期望速度在坡面上的投影分量"，四方向贴坡不走抛物线 |
| 命中判定 | 动画窗口 + 帧间胶囊/球体扫掠（与帧率无关），`HashSet` 按刀去重 |
| 防穿透 | 高速剑尖用独立碰撞体 + `Continuous` CCD + `MovePosition` 推进，飞行盾刚体用 `ContinuousDynamic`；召回盾用路径胶囊扫掠兜底物理隧穿 |
| 命中反馈 | 统一冲量标尺 `J = 武器速度 × 有效质量`（N·s），驱动受击摆动/布娃娃/箱子击飞三套表现 |
| 骨骼弹簧 | 欠阻尼角弹簧（`acc = −k·θ − c·ω`）驱动受击摆动：挥砍/爪击/盾砸统一走 `HitReaction` 上半身摆动，在 Animator 姿态后叠加 |
| 布娃娃 | 脚本运行时生成骨骼刚体（等价 Ragdoll Wizard），死亡唤醒 + 按命中部位分配冲量（含距离衰减） |
| 布料 | Verlet/PBD：结构/剪切/抗弯三类距离约束（统一刚度，逐轮全额投影） |
| 相机 | 半球面参数化轨道 + `SphereCast` 避障（拉近立即、推远渐进） |
| 时间 | 弹反用敌人 Animator 时间缩放实现局部"子弹时间"，全局 timeScale 不动 |

## 亮点设计

### 1. 一把标尺贯穿所有命中反馈

武器力度不写死成"伤害数值"，而是物理量 **冲量 J = 接触瞬间速度 × 有效质量（N·s）**：

- 箱子击飞：`ForceMode.Impulse` 在接触点施加 J（`PropImpulse`，偏心命中自动产生扭矩，带速度上限防弹射上天）；
- 受击摆动：`HitReaction` 按冲量定晃动幅度（欠阻尼弹簧回摆 1~2 次归零，`maxAngle` 饱和防穿模）；
- 死亡飞出：`Ragdoll` 按冲量定飞出强度，且**按命中部位分配**——命中点施加局部冲量、沿距离衰减，尸体以被砍中的部位为中心旋转飞出（"砍哪飞哪"）。

挥砍、爪击、投掷盾、召回盾共用这把尺子，新武器接入只需给出速度与质量。

### 2. 帧率无关的判定体系

- 挥砍/爪击判定是"上一帧位置 → 本帧位置"的胶囊/球体**扫掠**，低帧率大步长不漏判；
- 召回中的盾是 kinematic 逐帧瞬移，物理引擎的离散检测会隧穿敌人——另行维护路径胶囊扫掠兜底，物理消息只做提前精确结算；
- 布料模拟 dt 钳制在 1/30s，卡顿帧不会让布料爆炸。

### 3. 召回弧线

召回路径 = 直线插值 + 竖直正弦拱起 + 水平侧向绕行。命中敌人/石头需要中断召回时，用**同一条曲线对时间的导数**算出瞬时速度交给刚体——中断瞬间盾的弹开方向与它"本来在飞的弧线"切向完全一致，不会出现视觉与物理脱节。

### 4. 预瞄点

投盾预瞄用**与真实飞行完全相同的积分器**（同重力档、同阻尼、同步长）逐段步进 + 射线，取第一个命中点画圆——预测与实弹共用起点和参数。相机瞄准时拉近 + 越肩平移，靠视差把主角错开、预瞄点不被自己模型挡住。

### 5. 弹簧-阻尼骨骼反馈与程序化布娃娃

受击表现分两层：**存活 = 欠阻尼弹簧摆动，死亡 = 布娃娃物理接管**，两层共用同一把命中冲量（N·s）标尺，弹簧组件在死亡瞬间自动停手让位。

**统一上半身摆动（挥砍/爪击/盾砸，`HitReaction`）**
- 欠阻尼角弹簧逐帧积分：`angVel += (−k·θ − c·ω)·dt`（刚度 k=150、阻尼 c=12，欠阻尼 → 回摆 1~2 次自然归零）；受击瞬间往弹簧里注入角速度脉冲（满档 200 deg/s × 冲量缩放）；
- 幅度只取命中方向的**水平分量**：竖直分量是"压缩"不产生倾覆——带倾角的劈砍晃得轻、纯横扫最狠；角度钳在 ±14° 饱和，强击不穿模；
- 只叠加 spine（权重 1.0）与 head（0.5）：骨盆一旦旋转会带动整条腿、脚离地出戏；在 `LateUpdate`（Animator 写完姿态之后、渲染之前）叠加旋转，下一帧被 Animator 自动覆盖，无需恢复逻辑；摆动归零后立即停更（零开销）；
- 盾砸命中敌人走同一条路：`ShieldThrow` 调 `Health.TakeDamage` → `OnDamaged` 事件 → 进入这套弹簧，观感与挥砍/爪击一致。

**按骨骼局部受力（`ShieldHitReaction`，已实现、预留未接线）**
- 代码里另有一套与"统一晃"相反的独立方案：**砸中哪根骨头、哪根骨头转**——用"点到骨骼线段距离"定位被击中骨骼（存活期布娃娃部件是 kinematic 且碰撞检测已关闭，`Collider.ClosestPoint` 会退化失效，必须走纯几何线段距离）；力矩 `τ = r × J`（接触点相对骨骼旋转中心的力臂 × 命中冲量矢量）定出倾倒轴与强度，偏心命中按力臂放大（参考力臂 0.35 m，正中骨骼原点保底 0.7）；每根骨骼一个独立弹簧实例（字典管理、各自积分各自回摆），子链按 0.5 / 0.25 权重惯性传导；
- 但 `ShieldThrow` 当前并未调用它（`ReactAt` 无调用方）因为效果不明显，盾砸的实际受击表现就是上面的统一摆动。

**程序化布娃娃（`Ragdoll`，主角/敌人通用）**
- 脚本 `Build()` 等价 Ragdoll Wizard：18 个部件（胶囊体按相邻骨骼量长）+ `CharacterJoint` 链连接（swing ±60°、twist ±40°、`enableProjection` 防关节被拉散）；部件质量比控制在 3:1 以内——悬殊的质量比会让关节解算器发抖；
- 平时全部 kinematic + 关闭碰撞检测，完全由动画驱动、零开销；死亡瞬间停用 AI/动画（保留最后一帧姿势）、交出根刚体、唤醒骨骼物理；
- 飞出用 `VelocityChange`（不依赖质量，效果直观）：整体速度按部件到命中点的**距离衰减**（近快远慢 → 尸体绕命中点自然旋转），被砍中的部件再在接触点 `AddForceAtPosition` 施加局部冲量——力臂自动产生扭矩，砍腿踢飞腿、砍头上半身后仰；飞出方向直接取命中冲量方向，上挑真的挑上天、下劈真的砸向地。

**稳定性细节**
- 布娃娃专用层内部互不碰撞：肢体胶囊在骨盆/胸腔附近必然重叠，解算器不停推开它们是"尸体地上抽搐"的主因；
- 4 秒后加大阻尼让尸体安静下来，但**不冻结**——保持动态刚体留在场景里，被剑扫到/盾砸到还会动；
- 蒙皮网格包围盒改挂骨盆并放大 + 离屏也更新，防肢体飞散后被视锥剔除；相机跟随目标同步切到骨盆（否则镜头停在原地看空气）。

### 6. 程序化布料披风（Verlet/PBD）

不使用 Unity Cloth 组件，9×13 粒子 + 距离约束手工实现：

- **三类距离约束**：结构（横/纵，保布长）、剪切（对角，允许布面扭波浪）、抗弯（隔粒，允许打弯卷曲）；PBD 全额投影迭代求解（默认 8 轮，迭代越多布越硬挺、越不容易折叠塌陷）；
- **锚定贴合骨架**：顶行不是直线，而是"肩颈弧线"——中段包住后颈、两端角点改钉左右肩骨，抬臂时角点跟肩走；
- **两源风场**：环境微风（双正弦，沿背后吹 + 侧向摆动）+ 锚点运动相对风（与躯干运动反向：跑动后飘、原地转身甩摆、下落上飘都由锚点速度驱动，含竖直分量，带速度上限防动画突变帧把披风抽飞）；
- **身体碰撞推离**：胸腔/骨盆用沿相邻骨骼布置的胶囊段（比单球贴背，转身时侧缘不会从球缝漏进身体），头/大腿/肩用推离球，全部挂在骨骼上跟随动画（缺骨自动跳过）；推离是纯位置投影并同步修正 prevPos（防止修正位移被 Verlet 当成速度甩回去），带皮肤间距（粒子不穿 ≠ 三角面不穿），且在每轮约束迭代末尾执行、与约束求解交替收敛；
- **防缠绕**：粒子不许越过身体冠状面绕到胸前；
- 美术破损披风网格通过反距离权重绑定到粒子上跟随形变，布料物理与美术资产解耦。

### 7. 相机的物理化交互

- 半球面轨道：负仰角可沉到腰部以下仰视，配合地面抬升（视线方向不变）实现仰射瞄准；
- 避障：注视点向相机方向 `SphereCast`，**拉近立即（防穿墙）、推远渐进（防抖动）**；
- 投盾后进入"观察期"保持瞄准位看盾飞完全程，盾第一次碰撞再延拍 1 秒才回位；
- 弹反反击瞬间 `PunchZoom` 冲击拉近——角色前冲在硬跟随相机里看不出来，靠这一下把"撞上去"演出来。

### 8. 弹反的局部时间膨胀

子弹时间不动全局 `Time.timeScale`，只把敌人的 Animator 速度缩放 10 倍——玩家操作、相机、布料照常实时运行，"世界慢了但你没慢"的手感由此而来；反击的平推用水平初速度 + 动画速度自适应（滑停那一刻刚好播完），不抛物线弹飞。

### 9. 坡面贴合的速度投影

角色不用 CharacterController 而用 Rigidbody，坡上行走天然是"水平匀速 + 自由落体"的小抛物线。解法：腰部 `RaycastNonAlloc` 探地（过滤自身碰撞体，取最近外部命中），贴地范围内把竖直速度直接钉成期望水平速度在坡面上的投影分量——下坡吸附、横切等高线缓降、上坡沿坡爬升，翻过坡顶的残留爬升另行掐掉防止小跳。


## 运行

1. Unity Hub 安装 **6000.3.10f1**（或兼容的 Unity 6 版本），打开本项目；
2. 打开 `Assets/Scenes/SampleScene`，点 Play；
3. 游戏胜利条件，连续击败5个敌人
